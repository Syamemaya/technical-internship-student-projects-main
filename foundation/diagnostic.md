# 初级能力诊断

诊断用于选择合适的起点，不把结果包装成绝对能力结论。建议第一天在 30--40 分钟内完成，每项按 0、1、2 记录：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 运行程序 | 不能从终端运行 | 在提示下运行 | 可以独立运行并修改 |
| 值和输入 | 不能区分字符串和数字 | 能跟随示例修改 | 能独立处理输入和转换 |
| 条件和循环 | 不能预测分支或循环 | 能解释已有代码 | 能增加一个分支或循环 |
| 函数和测试 | 不能解释 return | 能修改给定函数 | 能写函数并增加断言 |
| Git 基础 | 不能创建分支或提交 | 在提示下完成 | 能独立 push 并查看 CI |

建议路由：

- 0--4 分：完成 B0 全部微任务；
- 5--7 分：完成 B0 中诊断失败的微任务，再进入初级项目；
- 8--10 分：可以直接进入初级项目，但仍需完成共同 Git 和环境验证。

诊断过程中不得要求学生完成算法题。重点是确认能否运行、修改、验证和解释一个极小程序。
