# 三选一项目总览

每个等级准备 3 个项目。学生只能选择对应等级的一个主项目，项目内再区分 Core 和 Stretch。

如果第一天诊断显示完全没有 coding 基础，先完成 [B00 基础起步门](../foundation/README.md)。B00 是前置训练，不占用初级三选一名额。

## 初级

目标：完成基础工程闭环，不要求算法题或 AI。

- [B01 命令行任务清单](beginner/B01-task-cli.md)
- [B02 数据清洗与报告](beginner/B02-data-report.md)
- [B03 小型 Web 功能切片](beginner/B03-web-slice.md)

## 中级

目标：完成一次可重复的机器学习、深度学习或强化学习实验。

- [M01 表格数据机器学习实验](intermediate/M01-tabular-ml.md)
- [M02 小型深度学习模型](intermediate/M02-small-dl.md)
- [M03 强化学习控制实验](intermediate/M03-rl-control.md)

## 高级

目标：完成 Agent 工程、Agent 评估或算法研究中的一个完整切片。

- [A01 工具调用 Agent](advanced/A01-tool-agent.md)
- [A02 RAG/Agent 评估系统](advanced/A02-agent-evaluation.md)
- [A03 论文复现与算法改进](advanced/A03-paper-reproduction.md)

## 项目卡的统一结构

每张项目卡都必须说明：

- 适合的基础和周期；
- 项目提供哪些 starter code、数据和基线；
- 学生实际要修改的核心代码；
- Core 验收用例；
- 必交材料；
- Stretch 扩展；
- 需要在哪些节点主动同步进展。
