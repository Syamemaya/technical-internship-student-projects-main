# Duration profiles

The level system remains beginner/intermediate/advanced. Duration changes the
depth of delivery, not the student's level.

| Duration | Required outcome |
|---|---|
| One week | Environment, Core implementation, tests, evidence and oral defense. |
| One month | One-week Core plus one evidence-backed iteration and a complete report. |
| Two months | A module or experiment with comparison, reliability review and handover. |
| Half year | A proposal, baseline, two iterations, hardening, feedback and final report. |

B00 is the one-week foundation deliverable for a learner with no coding
background. It is not a fourth beginner project.

## Evidence checkpoints

The assignment generator copies the selected profile into the student pack;
the following is the human-readable interpretation:

- **One week:** environment/diagnosis, Core implementation, one test or edge
  case, submission and oral explanation.
- **One month:** the one-week Core, a baseline-to-iteration comparison and a
  complete report.
- **Two months:** a defined module or experiment, at least one comparison,
  reliability/failure analysis, a midterm review and handover.
- **Half year:** proposal, baseline, two recorded iterations, user or peer
  feedback, hardening and a final report or technical handover.

Core remains the minimum. Stretch work must not create a second project line;
the machine-readable details are in `config/duration_profiles.json`.
