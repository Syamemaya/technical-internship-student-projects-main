# 课程与博客推荐清单

> 状态：v0.3。Bilibili 仍是主要观看媒介，但官方课程和文档现在构成技术主线；个人推荐用于补充视野，不再单独承担课程体系。本页和[官方课程与文档主线](official-courses.md)是给学生阅读的推荐入口。

## 定位

本目录只管理学习材料，不替代实践任务。学生应先阅读[官方课程与文档主线](official-courses.md)，再进入各等级路线；`catalog.json` 只是供脚本和维护者使用的机器可读元数据，不是课程推荐的主要阅读页面。学生最终仍需通过代码、实验、记录和现场说明完成验收。

第一天所有等级共同完成工具验证和学习材料记录。中间学习日按照初级、中级、高级路线选择与主项目匹配的材料，不要求学生把所有路线的课程全部看完。

## 推荐状态

| 状态 | 含义 |
|---|---|
| 官方主线 | 作为该等级技术学习的首选来源，开班前锁定小节和时长 |
| 已纳入推荐 | 已纳入本版清单，通常作为中文补充或问题意识材料 |
| 待锁定 | 方向已确定，但还没有锁定具体视频、合集或章节 |
| 可选材料 | 用于拓展视野，不作为主要技术验收依据 |
| 官方来源待核 | Bilibili 可能存在搬运或翻译版本，正式列为必修前先核对原始来源、字幕质量和授权/转载说明 |

## 统一完成记录

学生提交学习记录时，至少包含：

1. 材料名称、Bilibili 链接或站内搜索入口；
2. 实际观看的视频/章节和日期；
3. 一个自己理解的关键概念；
4. 一个没有在材料中原样出现的新问题，以及自己的迁移尝试；
5. 完成记录截图。截图只作为辅助证据，不能代替开放题、代码或现场说明。

## 使用和维护规则

- 课程推荐优先写“适合解决什么问题”，而不是堆积播放列表数量。
- 每条技术路线至少保留一门官方主线；Bilibili 入口用于降低观看门槛，不能替代官方来源。
- 完全零基础学生优先从 B00 的 Helsinki Python MOOC 或 CS50P 二选一，不被 3Blue1Brown、行业访谈或 AI 课程分流。
- 没有锁定具体视频时，先保留站内搜索入口；后续再固定 BV 号或合集。
- 行业访谈和技术博客主要用于建立问题意识、技术判断和表达能力，不把观点内容当成事实答案，也不直接替代技术课程。
- 学生发现清单之外的好材料，可以按第一天流程提交反馈，但不作为本轮主要考核。
