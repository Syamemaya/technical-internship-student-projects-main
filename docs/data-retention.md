# 数据留存与删除政策

## 范围

本政策适用于学生私有作业仓、assignment metadata、评分结果、现场答辩记录、`AI_USE.md`、日报以及 assignment ID 与真实身份之间的受限映射。

公开学生仓不得保存上述个人记录；真实身份映射和任何机构记录必须保存在机构批准且访问受限的系统中。

## 留存期限

- 从最终验收/结项日期起保留 30 个自然日；
- 30 天内用于处理成绩更正、申诉、技术复现和必要的交接；
- 到期后由当前管理员 `Densityyang` 删除学生私有仓、受限映射、评分和答辩记录；
- 删除台账只记录 assignment ID、删除日期、执行人和结果，不记录真实姓名或内容；
- 法律、机构政策或未结申诉需要延长时，必须记录原因、批准人和新的到期日期。

GitHub 服务端备份、审计日志和第三方平台的留存以其服务政策为准，不视为本项目可以控制的额外留存空间。

## 删除前检查

1. 结项结果已经登记；
2. 没有待处理的申诉、复现或交接；
3. 需要保留的匿名化工程经验已脱敏；
4. 私有作业仓、下载副本和本地 assignment artifacts 已清点；
5. 删除结果已写入受限删除台账。
