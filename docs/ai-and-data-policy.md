# AI 与数据使用政策

> 已确认：允许使用 AI，但必须披露、验证并在现场说明；AI 不替代 Core 验收。

## 可以做什么

- 可以使用 AI 解释概念、生成练习样例、提出测试用例、辅助重构或帮助定位错误。
- 最终提交必须由学生自己运行、阅读、修改并能够现场解释。
- 每次重要使用记录到 `AI_USE.md`：工具、目的、关键输入、保留或改写的内容、验证方式。

## 不可以做什么

- 不提交 API Key、访问令牌、简历、面试记录、联系方式、真实学生编号、生产数据或未脱敏的私有数据。
- 不把 AI 生成但自己没有理解的代码当作 Core 完成证据。
- 不把外部模型、在线 API 或付费服务作为短周期 Core 的隐含硬依赖；若使用，必须提供离线 fallback 或固定 trace。

## 验收边界

自动测试只判断可重复的技术条件。导师仍需通过现场提问确认学生理解关键决策、失败案例和 AI 参与边界。培训完成度与后续人才库/留用判断分开记录；本仓库不保存人才决策。
